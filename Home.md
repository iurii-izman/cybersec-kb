## Как пользоваться базой

1. Быстро записать сырые наблюдения в `00 Inbox`.
2. Найти существующую Concept, Technique или Tool заметку и дополнить её; новую создавать только для отдельной сущности.
3. Зафиксировать практику в Lab через Goal → Action → Evidence → Interpretation → Next Step.
4. Связать Lab с постоянными знаниями и периодически разбирать Inbox.
5. Запустить validator, просмотреть diff и сделать понятный commit.
